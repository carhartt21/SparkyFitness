# v45 release preparation

## Integrated changes

The clean `release/v45-20261006` candidate starts at main `87dfd7c86` and merges
`feat/v44-diary-refinement-20261006` at `b569138e1` without conflicts. This includes
the coaching OAuth consent and follow-up claim fixes already deployed separately,
so a full release preserves both hotfixes. The source includes compact Home,
dedicated training/health destinations, recorded/planned Diary sections, native
food moves, workout clocks and matching, 24-hour web inputs, Hevy import receipts
and Favorites handoff from native widgets. See the
[v44 correction record](v44-diary-refinement-2026-10-06.md) for behavior and screenshots.

Release review also found and corrected:

- Local hydration notifications contain `scheduledAt`, which the strict action
  schema rejected. Accept validated optional scheduling metadata and test the
  actual emitted payload shape, legacy compatibility and malformed metadata.
- Collapsed wellness rows hid the literal activity name. Show it in the row summary,
  preserving the existing expansion and dated undo flow.
- The new widget shortcut lacked a stable localization fallback; add the matching
  English fallback while retaining its reviewed German catalog entry.
- Update the measurement-order test to use an actual recorded measurement, and
  allow the workout-playback translation mock to accept standard i18next options.

There were no open GitHub PRs at the release review. Older v40 commits are
patch-equivalent to main. The historical weekly-activity branch is already
integrated as `d0a028f27`; the retained micronutrient backup is not a release
feature. Unfinished changes and private deployment edits in older checkouts are
preserved rather than copied over newer integrated implementations.

simulator evidence is reused for unchanged visual behavior; it does not establish
signed-device acceptance.
