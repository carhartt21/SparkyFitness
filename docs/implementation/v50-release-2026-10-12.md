# v50 release

## Scope and readiness

[Phone input refinements](phone-input-refinements-plan-2026-10-12.md) implements
the three reviewed Inbox findings: localized food quantity precision, shared
24-hour wheels for every phone clock input, and the selected hydration container
with its per-tap amount on Home. Date calendars, stored nutrition precision and
the existing hydration logging queue retain their behavior. There is no database
migration, dependency, native identity, entitlement or Watch change. The separate
upstream v1.8 adaptation branch is excluded.

All 583 mobile suites passed (7,952 tests); eight focused control tests passed
after the final supporting-line adjustment. Mobile, frontend and server validate
wrappers and the documentation build passed. Backend tests were skipped as
requested. The native German dark/light and enlarged-text interaction matrix passed. The
[finish review](evidence/v50-release-2026-10-12/finish-review.md) returned **ship**
within the changed-control scope, and the normal iOS export contains no review
markers. [Validation receipt](evidence/v50-release-2026-10-12/validation.json). Physical Android gestures, assistive
technology and paired-device acceptance remain separate checks.
