# v42 release preparation and delivery

## Included changes and review

The candidate combines the committed dashboard-density, whole-card progress
navigation, restrained widget motion, More tracking-grid, exact-time supplement
reminder grouping and mobility-session flow changes with Open Food Facts serving
ingestion. The integration merge is `4debac5d8`; `4898eafa4` adds release test
isolation and the safe-area context needed by header/menu tests.

- [Serving ingestion](open-food-facts-serving-ingestion-2026-10-04.md): preserve
  provider portions and their nutrient scaling through search, import and save.
- [Mobility](mobility-session-flow-2026-10-04.md): halfway cues, setup transitions,
  diary history and optional, consented Apple Health export with confirmed energy.
- [Supplement reminders](supplement-reminder-groups-2026-10-04.md): group only
  reminders at the exact same instant; keep medications and intake decisions separate.
- [Dashboard density](v41-dashboard-density-2026-10-04.md) and
  [motion](dashboard-widget-motion-2026-10-04.md): compact summaries, direct progress
  navigation and reduced-motion-aware feedback.

No open GitHub pull requests were returned. The older weekly-activity branch is
already integrated through `d0a028f27` and `79c0b3b9a`, with later corrective work;
merging that older implementation again would add no approved functionality.
Unrelated worktrees and their uncommitted work remain untouched. The only merge
conflict was the implementation index, resolved by retaining both entries.

Trust review found no dependency, install-hook, credential, authentication,
deployment configuration or migration change. No blocking runtime finding remains.

## Combined validation

The combined source passed frozen offline installation, all three package
validation wrappers, repository layout checks, production web/docs builds and a
production iOS Hermes export. Review-mode markers are absent from that export;
all 22 canonical artwork PNGs are bundled with their source hashes.

- Phone: **557 suites / 7,807 tests passed** in the final complete run.
- Web: **175 suites / 1,501 tests passed**.
- Server: **5 targeted suites / 100 tests passed**, covering serving mapping,
  persistence, mobility routes and shared diary projection. The blanket backend
  suite remains skipped under the standing owner instruction.
- Review harness: nutrition fixtures and runtime-error detector passed.
- German 390-point simulator: serving selection and mobility native interaction
  checks passed. Two 21.5 g portions display 43 g; transition, next timer and dated
  mobility diary navigation passed. Captures were inspected for text containment
  and usable controls.

The first full phone run exposed 15 failures because three test harnesses omitted
the safe-area provider now required by the popover. The tests now supply the app
shell's context; their assertions remain intact. The first combined simulator run
exposed stale synthetic mobility operations from an earlier scenario. All review
scenarios now clear only their isolated mobility storage before seeding. These
corrections affect tests/review mode, not production behavior.

[Bounded simulator evidence](evidence/v42-release-2026-10-05/validation.json)
records the base revision and fixture correction. Existing feature records retain
their broader dark/light and enlarged-text matrices. Native review uses the
existing compatible development simulator binary with current JavaScript; it is
not a signed production-archive check.

## Production and TestFlight preparation

Read-only preflight verified healthy production frontend/API at v41 source
`5aaf5ecb8`, all four serving-metadata columns, no pending migrations and **7,140
BLS foods**. About 6.3 GB of unused Docker build cache older than 24 hours was
reclaimed; rollback images, encrypted backups and persistent volumes were retained.

Preflight checked the existing guarded parallel release launcher and the
[TestFlight runbook](../../XoTMobile/docs/testflight-release.md). EAS and Apple
both reported build 41 as the latest release, with no pending newer EAS build.
Application version 1.7.2 and all signing/compatibility identifiers were retained.
The cloud production profile incremented to build 42 and automatically submitted;
no duplicate manual upload was made.

Pin both jobs to the same clean, pushed main revision. Capture current image IDs,
mounts and protected routing/configuration hashes. Require a fresh matched
encrypted backup with a checksum-verified off-host copy before switching services,
and retain automatic image rollback. Verify actual served assets as well as health.

Preserve rollout gates: `MICRONUTRIENT_IMPORT_ENABLED=false`,
`XOT_COACHING_ENABLED=false` and
`EXPO_PUBLIC_MICRONUTRIENT_SYNC_ENABLED=false`. No catalogue replacement, serving
backfill or historical snapshot rewrite is part of this release. Existing OFF
imports need a fresh provider selection to append missing portions; local barcode
matches and unexpired caches can continue showing older saved metadata.
