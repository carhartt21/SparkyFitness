# v48 release

## Integrated changes

The release includes the two completed phone refinements:

- [Dashboard brand header](dashboard-brand-header-2026-10-08.md): the approved stronger-outline E8 **X ON TRACK** lettering in dark/AMOLED, with the filled localized tagline, original controls and accessible identity. Light styling is retained. Static Space Grotesk glyphs include provenance and the upstream OFL license; only license whitespace was normalized during preparation.
- [More Browse rows](more-browse-2026-10-08.md): consistent shared grouped navigation rows, a semantic icon on every row, aligned typography/counts/chevrons and separators. Health & Routines no longer nests a second card inside the list.

There are no open GitHub PRs. The earlier v40 branch is patch-equivalent to main; the weekly-activity branch’s implementation and its later corrections are already integrated. The previously excluded micronutrient backup and unfinished legacy worktrees remain outside this release. No dependency, API, migration, native identity or entitlement change is included.
