## Release procedure and boundaries

Use the [TestFlight runbook](../../XoTMobile/docs/testflight-release.md) on a
clean, pushed main commit. EAS remote numbering was **43**, the prior cloud
build and automatic submission finished, and the five most recent cloud builds
contained no active build. Request **1.7.2 (44)** with automatic submission.

Production preflight found healthy frontend/API/database at v43 source
`6e72f1151`. Unused Docker build cache was cleared to satisfy the disk-space
guard; running and rollback images, volumes and backups were retained. Build
and deployment use the same pinned source and run concurrently. Deployment
requires a fresh matched encrypted backup verified off-host before switching,
and preserves protected settings, private routing, mounts, database image and
owner policies, with prior images/configuration retained for rollback.

Keep `MICRONUTRIENT_IMPORT_ENABLED`, `XOT_COACHING_ENABLED` and
`EXPO_PUBLIC_MICRONUTRIENT_SYNC_ENABLED` disabled. This release does not activate
cloud review tasks or change real goals, doses or historical nutrition.

Record cloud build, submission, Apple processing, signed-target inspection,
production HTTPS/API checks, catalogue/schema checks and served asset hashes
from actual results. Queue acceptance alone is not TestFlight availability.
Physical phone/paired Watch/Android checks and authenticated production visual
review remain outstanding; simulator fixtures and public smoke checks do not
replace them.
