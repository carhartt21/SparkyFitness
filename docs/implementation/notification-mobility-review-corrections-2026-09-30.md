## Test failures investigated

- Chat-service expectations now cover 67 tools and the 34-tool core profile, including mobility. All 55 chat-service tests pass.
- Water-reminder interval expectation now covers 1–12 hours, matching the shared contract.
- Navigation-header failures were caused by source parsers assuming one-line wrappers, one indentation level and literal formatting. The tests now accept formatter line breaks and stop each route at the next registration, while retaining native-header, back-button, action and suppression assertions. Application navigation behavior was not changed.
- The nutrition-reminder unchanged-request fixture omitted the content signature. It now reuses the request actually scheduled and checks that the second reconciliation neither cancels nor reschedules it.
- The email-login failure was not reproduced in this environment; the full server suite passes. No auth policy or expected HTTP status was changed to hide it.
