# Exercise search

Use exercise search to select an existing definition for activity logging, a workout preset or an advanced plan. Search by name; the existing library can also supply muscle-group/equipment metadata where available. Choose the correct exercise and tracking modality before entering sets, duration or distance.

A library definition is reusable. Selecting one does not record a completed workout. For repeated sessions, save the exercise sequence and planned sets as a preset; for a calendar schedule, use [Weekly training plans](/features/exercises/weekly-planning).

If an exercise is missing, create a private definition through the existing exercise-library flow. Do not recreate a definition merely because a provider/user name is in another language; first check its identity and available details. [MCP-based training](/features/exercises/mcp-training) can search/read the library too, with different permissions for writes.

For live set/rest tracking, start the workout from mobile. For completed activities, use the existing activity log and enter what actually happened. See [Exercise tracking](/features/diary/exercise).
