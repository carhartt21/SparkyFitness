# Exercise Tracking

X on Track lets you track exercise routines, including duration, intensity, sets, reps, weight, and calories burned. You can also import and sync routines from Health Connect (Android) or Apple Health using the [Mobile App](/mobile-app/mobile-app).

For high-intensity conditioning, interval timers, and CrossFit-style WOD scoring, check out the dedicated [Interval, Circuit & WOD Workouts](/features/exercises/interval-wod-workouts) guide.
