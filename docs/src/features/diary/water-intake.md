# Water Intake

On mobile, use the dashboard hydration card or **Quick Add (+) → Water** to
log water for the selected calendar day. Both surfaces use the same containers,
drink presets, configured goal and existing save/retry flow. Choose a container
or preset and record what you actually drank; a linked drink states its portion
instead of inventing a millilitre quantity.

Open the hydration details to inspect sources and dated history. Logged water,
drinks and supplement drinks count toward the hydration goal. Water in solid
food is shown in the details separately. Source water amounts need to be known;
missing nutrient values are not assumed to be zero. Linked drinks appear once
in the diary as food entries, and supplement drinks as intake entries.

Saved-on-device and attention-required water actions use the existing nutrition
outbox. Cached data can remain available offline; an uncached screen needs a
server connection. Retry an attention-required entry through the same logging
surface. Confirm reconciliation and native Health/Watch integration separately
on the signed app.
