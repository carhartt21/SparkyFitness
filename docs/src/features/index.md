# Features overview

X on Track separates plans, captured information and confirmed records. Use the guides below to complete a task and understand what the resulting summary means.

## Log and review

- [Meals and logging](/features/diary/meals), [nutrition summaries](/features/diary/nutrition-summary) and [exercise diary](/features/diary/exercise).
- [Check-in](/features/check-in), [measurements](/features/measurements), [goals](/features/goals) and [reports](/features/reports).
- [Medications and supplements](/features/supplements): classification, confirmed intake, reminders and assistant timing review.
- [FDDB import](/features/settings/fddb-import) for reviewing imported records separately from current daily meal routines.

## Plan and train

- [Weekly training plans](/features/exercises/weekly-planning) for activities and saved workouts.
- [Interval, circuit and WOD workouts](/features/exercises/interval-wod-workouts) for the existing tracking formats.
- [MCP-based training](/features/exercises/mcp-training) for evidence-based assistant workflows and supported write operations.

## Configure reminders and access

- [Settings](/features/user-settings) and [notifications](/features/settings/notifications).
- [Mobile installation](/mobile-app/mobile-app) and [widgets/Live Activities](/mobile-app/widgets-live-activities).
- [MCP connections](/features/mcp-server) and [family/friends sharing](/features/family-friends-sharing).

The [upstream comparison](/features/comparison) describes the parent project's feature set. It is not a release-status checklist for this owner app. Dated implementation/review records remain in the repository under `docs/implementation/`; use the feature guides for current usage.
