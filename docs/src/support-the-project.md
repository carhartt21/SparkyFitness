# Support the upstream project

X on Track builds on [SparkyFitness](https://github.com/CodeWithCJ/SparkyFitness) and retains its license and attribution. To support that upstream project, use its [GitHub issues](https://github.com/CodeWithCJ/SparkyFitness/issues) for upstream bugs and feature requests. Those links do not serve as X on Track release or support channels.
