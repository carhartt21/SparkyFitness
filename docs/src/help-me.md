# Help

Search these docs for X on Track setup, mobile workflows, and the upstream-compatible server configuration. When reporting a problem, include the app version, platform, steps to reproduce, and any safe-to-share error text. Do not post health records, server tokens, or private URLs.

The [SparkyFitness GitHub issues](https://github.com/CodeWithCJ/SparkyFitness/issues), [Discussions](https://github.com/CodeWithCJ/SparkyFitness/discussions), and [Discord](https://discord.gg/vcnMT5cPEA) belong to the upstream project. They can help with the upstream server, but they are not X on Track support channels.
