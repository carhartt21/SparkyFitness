# X on Track identity and migration

**X on Track · Keep getting better.** is the current owner-facing identity. [The Notion brand specification](https://app.notion.com/p/3e45fb777c5d81ce9afdfbb0c6e64524) and [decision D-23](https://app.notion.com/p/3e55fb777c5d81a7baf8fff86d8be308) supersede the earlier PersonalBest mark and name. SparkyFitness remains the upstream application and backend foundation, with its required attribution intact.

Active screen copy may contain old i18n **key names** such as `personalBestDescription` or `sparkyfitnessBurned`: keys are translation contracts and are not displayed. Catalog values and runtime brand substitution provide the displayed X on Track name while preserving Weblate keys. The Swift Watch app entry type and its source filename have been renamed because neither is a persisted identity. The Watch/widget **target names** stay unchanged because they bind native products and provisioning.

The public documentation includes upstream installation, legal, comparison, and support material. Those pages must identify SparkyFitness as the upstream source; they must not imply that its store listings, policy, or community channels are X on Track releases or support. The primary FAQ and mobile download page now make that distinction explicit.

The web release dialog is explicitly marked as an upstream SparkyFitness feed. Open Food Facts contribution attribution, Swiss Food requests, and OpenRouter's app title now identify X on Track; compatibility UUIDs and stored provider configuration are unchanged.

The X is a variable for a tracked dimension. “Nutrition on Track” and similar statuses are only appropriate when actual data supports them. The approved logo has a green chevron forming the left side of X, two orange segments on the right, and a converging track leading toward it. Its X forms are flat; the track fades toward the X. Do not substitute the earlier PB mark or the previously rejected vector reconstructions.

The mobile and web theme tokens now use the Notion forest/green and orange identity with a warm light field and charcoal dark field. Functional status colors retain their semantic meanings. The light-mode PR text uses a darker orange for readable contrast; the approved orange remains in brand artwork. These token changes need the light/dark and accessibility checks in the device gate before release.

## Assets

The Notion page embeds 320 px light and dark document previews made from the approved raster artwork. Those previews are preserved unchanged as `SparkyFitnessMobile/assets/brand/x-on-track-agreed-light.jpg` and `x-on-track-agreed-dark.jpg`, with the Notion wrapper SVGs alongside them. The named high-resolution originals, `minimalistisches_x_strassen_app_symbol.png` and `dunkles_x_logo_mit_perspektivbahn.png`, were referenced but not attached. The owner authorized the previews as the baseline for a new vector reconstruction; the new masters are **not** the missing original artwork.

The redraw preserves the flat green chevron, two orange strokes, three converging lanes, and upward track fade. It tightens the X crossing, makes the lane gaps consistent, and removes the preview's baked-in rounded-square mask and shadow so the OS can apply its own icon shape. The self-contained SVG masters are `SparkyFitnessMobile/assets/brand/x-on-track-light.svg` and `x-on-track-dark.svg`; matching 2048 × 2048 PNG exports are `x-on-track-light-2048.png` and `x-on-track-dark-2048.png`. All active mobile, web/PWA, Live Activity, and documentation raster sizes below now derive from those masters. The old PersonalBest source assets remain only as historical material.

## Compatibility boundary

This rebrand changes display names, permission text, auth email and passkey/TOTP labels, UI copy, and visible assets. The approved iOS identity is `com.cg.phi`, already used by the signed development build and the in-place iPhone test. The production/preview configuration previously contained the unavailable `com.SparkyApps.SparkyFitnessMobile` placeholder; it now uses the same `com.cg.phi` family and `group.com.cg.phi` App Group for all five targets. Android package IDs, the Expo project ID and `personalbest` slug, keychain/storage keys, schemes/deep links, Watch/widget target names, database keys, API routes, and source attribution are unchanged. Existing authenticator entries and passkeys may still show the earlier label until their OS-managed records are refreshed; their secrets and relying-party ID are unchanged. The old production iOS placeholder was not an installable upgrade path under the current Apple team.

## Release checks

Source verification on 25 September 2026: mobile validation, 475 Jest suites (7,192 tests), and development native-project generation passed. Web validation and production build, server validation and focused provider/attribution tests, and the documentation build passed. The web production output now has one X on Track install manifest, rather than a conflicting generated SparkyFitness manifest. The UI detector reported no remaining flagged patterns in the changed web components. The [corrected X on Track development IPA](https://expo.dev/accounts/ilmtech/projects/personalbest/builds/6b01dd43-3b8f-41fd-b1a3-d6c4bedd37a0) signed all five iOS bundles under the existing Apple team and identifiers. Its inspected English, German, Spanish, and French camera purpose strings include meal photography and barcode/nutrition-label scanning. The bundle identities and entitlements match the previous PersonalBest IPA; details are in the [physical-device gate](x-on-track-device-gate.md). That IPA predates the vector-derived icon exports and does not prove an in-place upgrade or Watch behavior on the physical pair.

Before publication, inspect the vector-derived icon in the iPhone launcher, Spotlight, notification, tinted icon, Watch, widget, Live Activity, PWA, and store sizes. Build all five signed iOS targets with the new artwork and verify an in-place upgrade retains the synthetic diary and authentication state. Test cold launch, permission prompts, notifications, and widget registration on the physical iPhone; complete Watch installation and sync checks through internal TestFlight before releasing Watch features. Record these in the [X on Track physical-device gate](x-on-track-device-gate.md). Prior PersonalBest build evidence remains in the [historical device gate](personalbest-device-gate.md); it is not evidence for the X on Track assets or display names.
