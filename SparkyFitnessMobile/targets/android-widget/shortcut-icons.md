# Launch shortcut icons

`res/drawable/ic_shortcut_activity.xml` and `ic_shortcut_measurements.xml` adapt
Google Material Icons' 24-pixel `directions_run` and `monitor_weight` SVG paths to
Android VectorDrawable syntax. Geometry is unchanged; fill uses system black.

Sources (retrieved 2026-09-26):

- https://github.com/google/material-design-icons/blob/master/src/maps/directions_run/materialicons/24px.svg
- https://github.com/google/material-design-icons/blob/master/src/device/monitor_weight/materialicons/24px.svg
